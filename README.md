# Make Your Game

A browser-based Space Invaders-style game built with vanilla JavaScript, HTML, and CSS.

The project was built as part of my software development studies to practice JavaScript, browser APIs, keyboard input, game logic, animation, and DOM-based rendering.

## Features

* Player-controlled spaceship
* Keyboard controls
* Shooting mechanics
* Enemy movement
* Collision detection
* Score tracking
* Game state management
* Animated game elements

## Tech Stack

* JavaScript
* HTML
* CSS
* Browser DOM APIs
* `requestAnimationFrame`

## Getting Started

No dependencies or build tools are required.

Open `index.html` in a modern web browser to play the game.

Alternatively, serve the project using a local HTTP server.
